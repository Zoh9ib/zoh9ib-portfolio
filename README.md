# Zoh9ib — Video Editor Portfolio

A responsive, cinematic one-page portfolio using plain HTML, CSS, and JavaScript. No framework, build tools, or paid services required.

## Files
- `index.html` — page content and four Instagram embed slots
- `style.css` — design and responsive layout
- `script.js` — tiny optional enhancement

## Add your Instagram edits
1. Open your own Reel or video post on Instagram in a browser and copy its URL.
2. Open `index.html` in a text editor.
3. Find `REPLACE_WITH_YOUR_REEL_1`, `REPLACE_WITH_YOUR_REEL_2`, `REPLACE_WITH_YOUR_POST_3`, and `REPLACE_WITH_YOUR_POST_4`.
4. Replace each entire `https://www.instagram.com/reel/REPLACE_WITH_YOUR_REEL_1/` placeholder value in `data-instgrm-permalink` with the full URL of the matching post. For example, a Reel URL looks like `https://www.instagram.com/reel/ABC123xyz/`; a post URL looks like `https://www.instagram.com/p/ABC123xyz/`.
5. Update the titles and category labels under each embed to match the project.
6. Instagram embeds require public posts and website embeds enabled on your Instagram account. Private posts will not display. The embeds are rendered by Instagram, so visitors may see Instagram's own player UI and may be prompted to open Instagram.
7. The page currently has four slots. Copy one `<article class="project instagram-project">...</article>` block to add another.

Double-click `index.html` to open it in a browser. Internet access is needed for the fonts, images, and Instagram embeds.

## Publish free with GitHub Pages
1. Create/sign in to a free GitHub account at https://github.com/
2. Create a **public** repository named `zoh9ib-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Go to repository **Settings → Pages**.
5. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
6. Wait a few minutes and copy the live URL shown in Settings → Pages. It usually looks like `https://YOUR-USERNAME.github.io/zoh9ib-portfolio/`.

## Important
- Hosting is free; a custom `.com` domain is not included.
- Don't upload private client footage or confidential files to a public repository.
- Instagram embeds show the specific posts you choose; they do not automatically swap to your newest posts.
